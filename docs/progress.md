## 4. ما تمّ إنجازه
### المرحلة 1: البنية والواجهة ✅
- **النواة `js/core/`:**
  - `utils` (h, shuffle, pick, textOn, bus)
  - `icons` (أيقونات SVG)
  - `store` (LocalStorage بالمفتاح `majlis.state.v1`)
  - `audio` (Web Audio)
  - `ui` (modal, confirm, toast, fullscreen, lightbox, field)
  - `bank` (أسئلة بلا تكرار)
  - `timer` (مؤقت محفوظ)
  - `teams` (الفرق واللاعبون والنقل)
  - `registry`
- **التطبيق:** `js/app.js` (التوجيه، الاستئناف، الإنهاء مع تأكيد، لوحة الإعدادات).
- **الألعاب:** `js/games/catalog.js` (بطاقات "قريباً")، و`js/games/counter.js` (عدّاد المجلس، مثال مرجعي).
- **واجهة اللعبة (ctx):** `ctx.session`, `ctx.save()`, `ctx.setting(k)`, `ctx.rerender()`, `ctx.onCleanup(fn)`.

### المرحلة 2: حروف ✅ (`game/huroof`)
- **الملفات:**
  - `js/games/huroof.js`
  - `js/data/huroof.js`: البيانات بالشكل `{ 'أ': [[سؤال, إجابة], ...] }`، وفيها 234 سؤالاً (8–9 لكل حرف).
  - تنسيق `/* ===== حروف ===== */` في آخر `css/style.css`.
  - سطرين في `index.html`.
- **الميزات:**
  - شبكة سداسية بـ 25 حرفاً (5×5)، أو 28 حرفاً من الإعدادات.
  - نافذة السؤال فيها: إظهار الإجابة، ومؤقت، وتغيير السؤال، وأزرار تلوين بألوان الفرق، ومسح اللون.
  - إعادة التوزيع مع تأكيد.
  - إعلان فائز الجولة **يدوياً**، مع عدّاد الجولات الفائزة.
  - مع فريقين: إطار ملوّن يوضّح الاتجاهات (الأول يصل الأعلى بالأسفل، والثاني اليمين باليسار).
  - حفظ كامل، حتى السؤال المفتوح.
- **الإعدادات:**
  - `timer`: الافتراضي 30 ثانية.
  - `autoTimer`
  - `size`: إما `25` أو `28`.
- **البنك:** معرّف بنك كل حرف هو `huroof:<الحرف>`. حرف الهاء مخزّن `ه` ويُعرض `هـ`.
- **الاختبار:** تمّ في متصفح Playwright على مقاس الكمبيوتر والجوال، بدون أخطاء.

### المرحلة 3: تحدي المئة ✅ (`game/feud`)
- **الملفات:** `js/games/feud.js`، `js/data/feud.js` (80 سؤالاً بالشكل `[سؤال, [[إجابة, نقاط], ...]]` مرتبة تنازلياً، المجموع ≤ 100)، تنسيق `/* ===== تحدي المئة ===== */`، سطرين في `index.html`، `tools/feud-export.js` → `docs/feud-review.md`.
- **الميزات:** بطاقات تنقلب بضغطة المقدّم وتضيف نقاطها لنقاط الجولة؛ زر «خطأ» مع Buzzer و❌ كبيرة؛ بعد الحد الأقصى من الأخطاء تبدأ فرصة السرقة (قلب بطاقة صحيحة = سرقة ناجحة، أو أزرار نجحت/فشلت، واختيار الفريق السارق إن كانوا أكثر من 2)؛ كشف كل البطاقات = فوز تلقائي؛ «منح النقاط الآن»؛ كشف الكل بعد الجولة؛ الجولة التالية تنقل الدور تلقائياً؛ تغيير السؤال مع تأكيد؛ لوحة نقاط (±5)؛ حفظ كامل.
- **الإعدادات (مع شرح تحت كل خيار):** `strikes` (3)، `multi` (الجولة 4 ×2، 6+ ×3)، `useTimer`، `timer` (20).
- **وضع المقدّم:** زر في شريط اللعبة (ليس في الإعدادات)، يُحفظ في الجلسة `s.host`، ويُظهر الإجابات خافتة على البطاقات.
- **قرار:** لا خانة كتابة للإجابة؛ المقدّم يقلب البطاقة بنفسه.
- **البنك:** معرّف `feud`. النقاط تقديرية (ليست من استبيان حقيقي).

### المرحلة 8: العميل السري ✅ (`game/codenames`)
- **الملفات:** `js/games/codenames.js`، `js/data/codenames.js` (478 كلمة، مصفوفة نصوص)، تنسيق `/* ===== العميل السري ===== */`، سطرين في `index.html`، `tools/codenames-export.js` → `docs/codenames-review.md`.
- **الميزات:** 25 بطاقة (البادئ 9، الآخر 8، محايدة 7، قاتلة 1)، يُختار البادئ عشوائياً؛ زر «المفتاح» مع تحذير ثم نافذة الألوان للقادة؛ إدخال التلميح (كلمة + رقم) ويُعرض للجميع؛ ضغطتين للكشف (تحديد ثم كشف)؛ لون الفريق = يكمل، محايدة/الخصم = ينتهي الدور، القاتلة = خسارة فورية؛ كشف كل بطاقات فريق = فوزه (حتى لو كشفها الخصم)؛ إنهاء الدور يدوياً؛ لعبة جديدة مع تأكيد؛ عدّاد الانتصارات؛ سجل اللعبة؛ حفظ كامل. تُلعب بأول فريقين فقط.
- **الإعدادات (مع شرح):** `confirmTap` (ضغطتين)، `limit` (التخمينات = الرقم + 1)، `useTimer`، `timer` (90).
- **البنك:** معرّف `codenames` (25 كلمة بلا تكرار عبر الألعاب).
- **ملاحظة تقنية:** `root.append` يكتب `null` كنص؛ استخدم `.filter(Boolean)` قبل الإضافة. (أُصلح في حروف أيضاً، مع إصلاح زر «مسح اللون».)

### المرحلة 7: إمبراطور الكلمات ✅ (`game/emperor`)
- **الملفات:** `js/games/emperor.js` (بدون ملف بيانات)، تنسيق `/* ===== إمبراطور الكلمات ===== */`، سطر في `index.html`.
- **المراحل داخل اللعبة:** `setup` (إضافة لاعبين يدوياً أو «جلب أسماء الفرق»، 3+) ← `write` (تمرير الجهاز، كل لاعب يكتب كلمته سراً، منع التكرار مع تجاهل ال/الهمزات/ة) ← `read` (عرض الكلمات عشوائياً + خلط) ← `play` (الإمبراطور صاحب الدور يضغط بطاقة إمبراطور آخر ثم يختار الكلمة من نافذة؛ صح = يضمّه مع أتباعه ويكمل، خطأ = الدور للمستهدف) ← `over` (آخر إمبراطور يفوز، كشف من كتب ماذا).
- **الإعدادات (مع شرح):** `topic` (نص)، `showList`، `useTimer`، `timer` (30).
- **أخرى:** لعبة/جولة جديدة وتعديل اللاعبين مع تأكيد، عدّاد انتصارات بالأسماء، سجل، حفظ كامل. اللعبة فردية (`teams: null`).

### المرحلة 6: برا السالفة ✅ (`game/outsider`)
- **الملفات:** `js/games/outsider.js`، `js/data/outsider.js` (15 تصنيفاً × 25 كلمة، نص مفصول بـ «،»)، تنسيق `/* ===== برا السالفة ===== */`، سطرين في `index.html`. (الفرع لم يكن فيه مجلد `docs` فأُنشئ.)
- **المراحل داخل اللعبة:** `setup` (3+ لاعبين، يدوي أو من الفرق) ← `reveal` (تمرير الجهاز: الداخل يرى التصنيف والكلمة، اللي برا يرى «أنت برا السالفة» + التصنيف إن كان الإعداد مفعّلاً) ← `ask` (دائرة بترتيب عشوائي: كل لاعب يسأل اللي بعده، فالكل يسأل مرة وينسأل مرة؛ ثم دورة ثانية بترتيب جديد أو التصويت؛ زر «شوف دورك مرة ثانية») ← `vote` (جماعي: اختيار المتهم؛ أو سري بتمرير الجهاز مع عدّ الأصوات وحل التعادل يدوياً) ← `guess` (إن انكشف: يختار الكلمة من 8 خيارات من نفس التصنيف) ← `over`.
- **النقاط:** انكشف وما عرف = +1 لكل الداخلين؛ انكشف وعرف = +2 له؛ ما انكشف = +2 له. نقاط بالأسماء + تصفير + سجل.
- **الإعدادات (مع شرح):** `cat` (عشوائي أو تصنيف)، `outs` (1 أو 2، اثنين يحتاج 6+)، `knowCat` (مفعّل افتراضياً)، `vote` (`group`/`secret`)، `useTimer`، `timer` (30، لكل سؤال).
- **البنك:** معرّف `outsider:<التصنيف>`.

### المرحلة 9: بدون كلام ✅ (`game/taboo`)
- **الملفات:** `js/games/taboo.js`، `js/data/taboo.js` (263 بطاقة، كل سطر «الكلمة: 5 ممنوعات» مرتبة من الأوضح)، تنسيق `/* ===== بدون كلام ===== */`، سطرين في `index.html`.
- **اللعب:** `ready` (الفريق + الشارح بالتناوب من لاعبي الفريق) ← `play` (المؤقت يبدأ تلقائياً؛ البطاقة: الكلمة + الممنوعات؛ أزرار صح +1 / تخطي / ممنوع −1؛ إنهاء الدور يدوياً) ← `end` (ملخص الدور، الضغط على بطاقة يغيّر نتيجتها، ثم اعتماد) ← بعد كل الأدوار: أعلى نقاط يفوز، التعادل = جولة حاسمة للمتعادلين ← `over`.
- **الإعدادات (مع شرح):** `diff` (سهل 3 / صعب 5)، `rounds` (3)، `time` (60)، `skipPenalty`، `skipLimit` (0 = بلا حد).
- **البنك:** معرّف `taboo`.

### المرحلة 11: المزايدة ✅ (`game/bid`)
- **الملفات:** `js/games/bid.js` (يسجّل نفسه كاملاً لأن الكتالوج ما فيه بطاقته)، `js/data/bid.js` (152 سؤال تعداد، كل سطر «السؤال | أمثلة»)، تنسيق `/* ===== المزايدة ===== */`، سطرين في `index.html`.
- **اللعب:** `bid` (الفريق صاحب الدور يرفع الرهان بعدّاد +/− و+1/+2/+5، أو يضغط «عدّدها!» على آخر رهان؛ الدور يدور بين الفرق؛ تغيير السؤال مع تأكيد بعد بدء المزايدة) ← `count` (المؤقت يبدأ تلقائياً؛ المقدّم يضغط «إجابة صحيحة»، تراجع، فشل/استسلم؛ أمثلة للمقدّم) ← `done` (الوصول للعدد = النقاط للمراهن، غير ذلك = لمن تحدّاه) ← بعد الجولات: أعلى نقاط، التعادل = جولة حاسمة ← `over`. البادئ يتناوب كل جولة.
- **الإعدادات (مع شرح):** `points` (نقطة / بعدد الرهان)، `rounds` (6)، `timerMode` (لكل إجابة / ثابت)، `perSec` (3)، `fixed` (45)، `minRaise` (1)، `hints`.
- **البنك:** معرّف `bid`.

## 5. القرارات المتّخذة
- **حروف:** الفوز يدوي، لأن السؤال قد يتغيّر بعد التلوين أو يُعاد.
- **تحدي الصور:** أُلغيت. **بدون كلام:** أُلغيت ثم أُعيدت.
- **مكان الملفات:** في جذر المستودع، مع فرع لكل لعبة وفرع للموقع وفرع للتصميم.
- **Git:** لا commit ولا push إلا بإذن صريح في نفس الرسالة، حتى لو جاء تنبيه آلي من النظام.

## 7. خطوات Claude بعد كل مرحلة
1. اختبار اللعبة في Playwright (`file://.../index.html#/game/<id>`)، والتأكد أنه لا توجد أخطاء ولا تمرير أفقي.
2. تحديث رابط المعاينة بنفس الرابط.
3. تحديث هذا الملف (الأقسام 1 و3 و4 و6)، وتحديث جدول المراحل في `docs/rules.html`، ثم توليد الـ PDF.
4. إرسال zip للمشروع + هذا الملف + الـ PDF للمستخدم.
5. طلب الإذن للـ commit والـ push، ثم شرح المرحلة التالية وانتظار الموافقة.
